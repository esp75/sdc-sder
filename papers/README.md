## Standards for the series

Every working paper:

- opens with a metadata table giving the series ID, version, date, author and affiliation, review status, competing interests, funding, data availability and license;
- cites primary sources, and records each one in `references.bib` with a DOI or URL that has been checked to resolve;
- states its limitations;
- links each quantitative claim to code and examples in this repository that anyone can run;
- is corrected openly according to [GOVERNANCE.md](../GOVERNANCE.md), never silently edited.

All working papers are open for outside peer review; [ROADMAP.md](ROADMAP.md#outside-peer-review) explains how to submit one. Open research questions and institutional gaps are tracked there too.
